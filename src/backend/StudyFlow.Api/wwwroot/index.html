Vue d'ensemble

Un outil simple pour la vie de classe et la période d'alternance.

01

Organisation scolaire

Planning, devoirs, matières et échéances regroupés dans une interface lisible.

02

Vie de classe

Annonces officielles, ressources et gestion des membres par les délégués.

03

Alternance

Recherche publique d'offres, favoris et suivi personnel pour les futurs élèves.

Modules

Le projet garde le côté scolaire et le côté entreprise dans le même flux.

StudyFlow peut servir pendant les cours, puis accompagner les relances, entretiens, contacts entreprise et offres d'alternance sans créer un outil séparé.

Recherche alternance Accessible publiquement sans compte. Agenda et devoirs Conçu pour suivre la classe au quotidien. Ressources et annonces Une base claire pour les informations importantes.
