Produit

Une application pensée pour la routine réelle d'une classe.

L'objectif n'est pas de remplacer tous les outils, mais de regrouper les informations scolaires importantes dans un espace clair et fiable.

01

Planning et devoirs

Cours, tâches, échéances et progression personnelle dans un parcours mobile.

02

Vie de classe

Annonces, ressources, code de classe et validation par les délégués.

03

Alternance

Recherche publique d'offres, favoris et entraide alternance côté classe.

Architecture

Une base simple à expliquer, tester et déployer.

Client

Flutter pour iPhone, Android, web et desktop. Le mode release peut pointer vers l'URL DuckDNS.

API

ASP.NET Core, JWT, contrôleurs REST, endpoint public alternance et fichiers statiques du site.

Données

PostgreSQL avec migrations Entity Framework et données de démonstration en développement.

Déploiement

Docker Compose sur NAS, reverse proxy HTTPS, DuckDNS et tests avec /api/status.

Ce qui existe

Le projet est utilisable en local, en démo et depuis le NAS.

StudyFlow garde plusieurs chemins de lancement : démo sans backend, backend local pour développer, et API NAS pour tester sur iPhone sans garder le Mac allumé.

Recherche alternance publique Accessible sans compte depuis le navigateur. Statut API Contrôle rapide du backend exposé par le NAS. Documentation de déploiement Commandes NAS, Docker, reverse proxy et tests.
